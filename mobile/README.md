# EYEPEK Mobile App (Flutter)

This folder contains the Flutter Android/iOS application. It is kept separate from the existing Vite website so the live website is not disturbed.

## Requirements
- Flutter SDK
- Android Studio / Android SDK

## Run
```bash
cd mobile
flutter pub get
flutter run
```

Create the initial Flutter platform folders locally with `flutter create .` from this directory if they are not present yet.

The app uses EYEPEK's blue-and-white brand direction. The first screen lists College, Student, Computer, IT, Online Support and Media services.

No API keys, passwords, or production credentials belong in this public repository.
